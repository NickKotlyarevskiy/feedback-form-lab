# Feedback form — самостоятельная работа

Проект состоит из двух PHP-страниц:

- `index.php` — форма обратной связи с отправкой методом `POST` на `https://httpbin.org/post`.
- `headers.php` — серверный вызов PHP-функции `get_headers()` для `https://httpbin.org/get`; полученный результат выводится в `textarea`.

Общие части сайта находятся в `includes/`, оформление и логотип — в `assets/`.
